IEMS Template

IEMS (includes/templates/iems/) started as a complete, standalone copy of the ZCA Bootstrap-4 template (includes/templates/bootstrap/). It does not depend on Bootstrap at runtime and does not modify any core Zen Cart files. Every file IEMS needs is physically present under its own template directory (and the matching per-template includes/modules/, includes/modules/sideboxes/, and includes/languages/ directories, described below). IEMS can be edited freely without any risk to Bootstrap or to other templates.

Why a full copy instead of a "parent template" mechanism

An earlier iteration of this work experimented with extending Zen Cart's core template-resolution and language-loading code so that a "child" template (IEMS) could automatically inherit any file it didn't override from a declared "parent" template (Bootstrap), without duplicating files. That approach was abandoned for two reasons:

  • It required modifying core files (includes/init_includes/init_templates.php, includes/classes/ResourceLoaders/PageLoader.php, includes/functions/html_output.php, and the language-loader classes) — changes to shared core code are out of scope unless explicitly requested.
  • Auditing it further surfaced a real design gap: Zen Cart's pattern-based, multi-file directory scans (used for example by the CSS loader to find all style*.css/print*.css files, and by the JS loader for all jscript_*.js files) resolve to a single winning directory (child or parent), then list only the files in that one directory. The moment a child template shipped even one file matching such a pattern, the parent's other matching files would be silently dropped entirely — a subtle, hard-to-detect class of bug (missing CSS/JS → broken spacing/sizing) that would be easy to reintroduce later.

All core-file changes from that experiment have been fully reverted; the core files listed above are byte-identical to their state before this work began. includes/templates/bootstrap/ itself was never modified. IEMS is now a fully self-contained copy instead.

What was copied

Source (Bootstrap)Destination (IEMS)Contents
includes/templates/bootstrap/ includes/templates/iems/ Full recursive copy (182 files): common/, templates/, sideboxes/, centerboxes/, modalboxes/, css/, jscript/, images/, buttons/, template_info.php, etc.
includes/modules/bootstrap/ includes/modules/iems/ Per-template module overrides (e.g. categories_tabs.php, product_listing.php, attributes.php, and the centerboxes/ subfolder) resolved dynamically at runtime by zen_get_module_directory() based on the active template's directory name. Required: Bootstrap's own copied template files reference these by filename only, and zen_get_module_directory() does not fall back to any other template's directory if the active template's own copy is missing.
includes/modules/sideboxes/bootstrap/ includes/modules/sideboxes/iems/ Per-template sidebox overrides (e.g. search_header.php, information.php, more_information.php), resolved the same way by zen_get_module_sidebox_directory().
includes/languages/bootstrap/lang.english.php includes/languages/iems/lang.english.php Main per-template language file (defines constants such as TEXT_MISSING_SHIPPING_INFO used by inherited-style page templates).
includes/languages/english/extra_definitions/bootstrap/*.php includes/languages/english/extra_definitions/iems/*.php Extra per-template language definitions (e.g. TEXT_HEADER_ARIA_LABEL_NAVBAR, BOOTSTRAP_PLEASE_SELECT) referenced by the copied common templates.

Each copy above was verified byte-identical to its Bootstrap source via diff -rq at the time of copy.

Going forward

Because IEMS is now a complete, independent copy, it can be edited directly — there is no "inherited vs. overridden" distinction to track anymore. When Bootstrap itself receives upstream updates, review its changelog and manually port relevant fixes into the corresponding IEMS files if desired; IEMS will not pick them up automatically.
