IEMS Template

IEMS (includes/templates/iems/) is a "child" template built on top of the ZCA Bootstrap-4 template (includes/templates/bootstrap/). It does not duplicate Bootstrap's files. Instead, it declares Bootstrap as its parent template ($template_parent = 'bootstrap'; in includes/templates/iems/template_info.php), and the core template-resolution code automatically serves any file IEMS doesn't ship from Bootstrap, and anything neither of them ship from template_default.

How the inheritance works

Zen Cart normally only supports a single fallback: current template → template_default. This was extended (see "Core changes" below) so a template can name a parent template to check first: 

current template (iems) → parent template (bootstrap) → template_default

Resolution order used for every template lookup ($template->get_template_dir() / $template->get_template_part(), which covers common/, templates/, sideboxes/, centerboxes/, modalboxes/, css/, jscript/, images/, buttons/, etc.), plus the zen_image()/zen_image_OLD() image-src fallback:

  1. includes/templates/iems/<page-specific subfolder>/
  2. includes/templates/bootstrap/<page-specific subfolder>/
  3. includes/templates/template_default/<page-specific subfolder>/
  4. includes/templates/iems/<generic subfolder>/
  5. includes/templates/bootstrap/<generic subfolder>/
  6. installed zc_plugins template dirs
  7. includes/templates/template_default/<generic subfolder>/ (final fallback)

Core changes that enable this

  • includes/init_includes/init_templates.php — after resolving the active $template_dir, reads the (optional) $template_parent variable from that template's template_info.php and, if the named parent template exists on disk, defines the DIR_WS_TEMPLATE_PARENT constant.
  • includes/classes/ResourceLoaders/PageLoader.php (getTemplateDirectory()) — consults DIR_WS_TEMPLATE_PARENT (when defined) between the current template and template_default.
  • includes/functions/html_output.php (zen_image() / zen_image_OLD()) — same parent-template fallback for template-relative image src paths that aren't resolved through get_template_dir().
  • includes/classes/ResourceLoaders/CatalogArraysLanguageLoader.php and CatalogFilesLanguageLoader.php (loadLanguageExtraDefinitions()) — language constants defined in a template's includes/languages/english/extra_definitions/<template>/ directory (e.g. TEXT_HEADER_ARIA_LABEL_NAVBAR in includes/languages/english/extra_definitions/bootstrap/) are now also loaded from DIR_WS_TEMPLATE_PARENT's directory, before the child template's own extra_definitions (which still win if present). Without this, any page inherited unmodified from Bootstrap that references a Bootstrap-only language constant would hit an "Undefined constant" fatal error when IEMS is the active template.

Existing templates are unaffected: $template_parent is opt-in (defaults to none), so any template that doesn't declare it behaves exactly as before.

Files overridden by IEMS (as of initial scaffold)

FilePurpose
includes/templates/iems/template_info.php Template metadata; declares $template_parent = 'bootstrap'.
includes/templates/iems/template_settings.php IEMS-specific $tpl_settings[] overrides (e.g. TEMPLATE_NAME).
includes/templates/iems/css/site_specific_styles.php IEMS branding/style overrides, loaded last (after Bootstrap's own CSS) by the inherited common/html_header_css_loader.php.
includes/templates/iems/images/ZCA_BOOTSTRAP_TEMPLATE.png Placeholder admin "Layout Controller" screenshot; replace with an IEMS-specific screenshot.
includes/templates/iems/jscript/jscript_framework.php Verbatim copy of Bootstrap's file (no IEMS-specific change needed). It simply requires template_default/jscript/jscript_framework.php to load the AJAX framework for any non-template_default template. Present here explicitly rather than relying on parent-template inheritance.

Files inherited from Bootstrap (not present in IEMS)

Everything else — all of includes/templates/bootstrap/common/, templates/, sideboxes/, centerboxes/, modalboxes/, jscript/, and the base Bootstrap/Font-Awesome css/ files (e.g. stylesheet.css, stylesheet_bootstrap.carousel.css, bootstrap_color_vars.php, etc.) — is inherited unmodified from includes/templates/bootstrap/. Notably:

  • common/html_header.php, tpl_header.php, tpl_footer.php, tpl_main_page.php, tpl_columnar_display.php, tpl_tabular_display.php
  • All templates/tpl_*.php page templates
  • All sideboxes/, centerboxes/, and modalboxes/ partials
  • jscript/jscript_zca_bootstrap.js, jscript_framework.php, etc.
  • css/stylesheet.css, css/bootstrap_color_vars.php, and the other base Bootstrap stylesheets

As IEMS-specific behavior is developed, override individual files by copying them from includes/templates/bootstrap/ into the matching path under includes/templates/iems/ and modifying the copy. Update this document's "overridden" table whenever a new file is added to IEMS.

Modules and language files

includes/modules/bootstrap/, includes/modules/sideboxes/bootstrap/, and includes/languages/bootstrap/ are separate module/language directories that Bootstrap's own template templates reference directly by name (not through the template/parent fallback described above). IEMS currently reuses these as-is; if IEMS needs its own module or language overrides, add matching includes/modules/iems/, includes/modules/sideboxes/iems/, or includes/languages/iems/ directories and update the referencing template files.
